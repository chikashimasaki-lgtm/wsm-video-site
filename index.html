このアプリについて

最終更新: 2026年9月20日

wsm_tts_youtubeは、運営者が個人で利用するために作った非商用のツールです。 手元でスキャン・OCR した書籍や資料の Google ドキュメントを読み上げ音声つきの動画に変換し、 運営者自身の YouTube チャンネルへ非公開（限定公開）でアップロードします。 移動中などに「読む」代わりに「聞く」ための、個人的な用途を目的としています。

一般公開のサービスではありません。 利用者は運営者本人ひとりだけで、アカウント登録の窓口や外部への提供はありません。 処理はすべて運営者自身の Google Cloud プロジェクト内で完結します。

できること

  • Google ドキュメントの本文を読み取り、読み上げ用のテキストに整形する
  • Google Cloud Text-to-Speech で読み上げ音声を合成する
  • ページ画像と音声を合成して動画ファイルを作る
  • できた動画を YouTube へ非公開でアップロードする
  • 目次から YouTube のチャプターを作り、字幕（SRT）を登録する
  • 処理の進捗と結果を Google スプレッドシートに記録する

動作のしくみ

変換したいドキュメントを Google スプレッドシートの待ち行列に登録すると、 Google Cloud Run 上のジョブがそれを受け取り、読み取りから動画化、アップロードまでを一気に行います。 処理は Google のサーバー上で動くため、手元の端末を起動しておく必要はありません。

アクセスする情報

このアプリが Google アカウントに求める権限は、次の4つだけです。用途は下表のとおりです。

権限（スコープ）用途
documents.readonly 変換元の Google ドキュメントを読み取る（書き込みはしません）
spreadsheets 待ち行列のスプレッドシートに処理状況・動画URL・エラーを記録する
youtube.upload できた動画を自分のチャンネルへ非公開でアップロードする
youtube.force-ssl アップロードした動画に字幕を登録する

これらは運営者自身のドキュメント・スプレッドシート・YouTube チャンネルに対してのみ使われます。 扱いの詳細はプライバシーポリシーをご覧ください。

使っている技術

  • Google Cloud Run（ジョブ実行）
  • Google Docs API / Google Sheets API
  • Google Cloud Text-to-Speech（音声合成）
  • Vertex AI（目次からのチャプター生成）
  • YouTube Data API v3（アップロード・字幕登録）
  • ffmpeg（動画の合成）
