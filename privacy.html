プライバシーポリシー

最終更新: 2026年9月20日

自動化ツール共通（以下「本アプリ」）は、運営者が個人で利用するために作成した非商用のツールです。 本ポリシーは、本アプリが Google ユーザーデータをどのように取得・利用・保存・削除するかを説明します。

要約：本アプリの利用者は運営者本人のみです。 本アプリは運営者自身のドキュメント・スプレッドシート・YouTube チャンネルだけを扱い、 取得したデータを第三者へ販売・提供・共有することは一切ありません。 広告配信や行動追跡も行いません。

1. 運営者

  • 運営者: Chikashi Masaki（個人）
  • 連絡先: chikashi.masaki@gmail.com

2. 取得する情報

本アプリが取得するのは、運営者が Google アカウントで明示的に許可した範囲の次の情報だけです。

権限（スコープ）取得・操作する内容目的
https://www.googleapis.com/auth/documents.readonly 指定した Google ドキュメントの本文テキストと、そこに含まれるページ画像 読み上げ原稿と動画の映像を作るため（読み取りのみ・書き込みなし）
https://www.googleapis.com/auth/spreadsheets 待ち行列として使う Google スプレッドシートの読み書き 処理の状態・完成した動画のURL・エラー内容を記録するため
https://www.googleapis.com/auth/youtube.upload YouTube チャンネルへの動画アップロード 完成した動画を非公開で保存するため
https://www.googleapis.com/auth/youtube.force-ssl アップロードした動画への字幕登録 読み上げ内容に対応する字幕を付けるため

本アプリは、氏名・住所・電話番号・支払い情報などの個人情報を、上記とは別に収集することはありません。 Gmail、連絡先、カレンダー、Google ドライブ全体へのアクセス権は要求しません。

3. 情報の利用目的

取得した情報は、次の処理を実行する目的にのみ利用します。

  • ドキュメント本文から読み上げ用テキストを組み立てる
  • 読み上げ音声を合成し、ページ画像と合成して動画ファイルを作る
  • 目次情報から動画のチャプターと説明文を作る
  • 動画と字幕を運営者自身の YouTube チャンネルへ非公開でアップロードする
  • 処理の進捗・結果・失敗理由をスプレッドシートへ記録する

これ以外の目的（広告、プロファイリング、機械学習モデルの学習、統計の外部提供など）には利用しません。

4. 第三者への提供

取得したデータを第三者へ販売・貸与・提供することはありません。 処理の過程で、Google が提供する以下のサービスにデータが送信されますが、 いずれも運営者自身の Google Cloud プロジェクト内で、上記の処理を実行する目的に限って利用されます。

  • Google Docs API / Google Sheets API（読み取り・記録）
  • Google Cloud Text-to-Speech（音声合成）
  • Vertex AI（目次からのチャプター生成）
  • YouTube Data API v3（アップロード・字幕登録）
  • Google Cloud Run / Cloud Logging（実行基盤と実行ログ）

法令にもとづく開示請求があった場合を除き、これ以外への提供は行いません。

5. 保存と保護

  • Google アカウントのアクセストークンおよびリフレッシュトークンは、 運営者の Google Cloud プロジェクト内の Secret Manager に保管し、 実行時にのみジョブへ読み込みます。ソースコードや公開リポジトリには含めません。
  • ドキュメント本文・音声・動画などの中間ファイルは、処理を実行するコンテナ内の一時領域にのみ作られ、 ジョブの終了とともに破棄されます。永続的なデータベースには保存しません。
  • 完成した動画は運営者自身の YouTube チャンネルに非公開として保存されます。 公開範囲の管理は YouTube 上で運営者が行います。
  • 処理の記録（日時・ドキュメントID・状態・動画URL・エラー内容）は、 運営者自身の Google スプレッドシートに残ります。
  • 実行ログは Google Cloud Logging に保存され、同サービスの保持期間の経過後に削除されます。

6. データの削除とアクセス権の取り消し

本アプリに与えたアクセス権は、いつでも次の方法で取り消せます。

  • Google アカウントの「サードパーティ製アプリとサービス」 から本アプリを削除する
  • Secret Manager に保管したトークンを削除する

取り消し後、本アプリは Google ユーザーデータへ一切アクセスできなくなります。 すでにアップロードされた動画やスプレッドシートの記録は運営者自身の管理下にあるため、 不要であれば YouTube およびスプレッドシート上で直接削除してください。 削除のご依頼や確認は、上記の連絡先までご連絡ください。

7. Google API サービスユーザーデータポリシーの遵守

本アプリによる Google API から受け取った情報の利用と他アプリへの移転は、 Google API サービスのユーザーデータに関するポリシー （Limited Use（限定的な使用）の要件を含む）に準拠します。

8. Cookie・アクセス解析

本ウェブサイトは静的なページのみで構成されており、Cookie の発行、アクセス解析、広告配信は行いません。

9. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、冒頭の最終更新日を改めます。
